# Rubric-Grounded Essay Feedback with Evidence Citation

A small local portfolio project demonstrating document extraction, rubric-based
essay feedback, exact evidence quotations, and a faculty review step.

## Local demonstration

The default UI has four simple parts:

1. **Overview** — project purpose and role switch.
2. **Student demo** — upload a PDF or UTF-8 TXT essay.
3. **Evaluation results** — inspect criterion feedback, exact source quotations,
   character offsets, and extracted text.
4. **Faculty demo** — review submissions, approve them, or request changes.

The predefined rubric contains Content and relevance, Grammar and vocabulary,
Essay structure, Critical thinking, and Clarity and coherence, each weighted
20%. Results are generated by deterministic, transparent heuristics and are
labelled **DEMO-GENERATED — NOT AI**. The normal demonstration workflow does not
use or require an OpenAI API key.

The demo API stores evaluations in backend process memory. They are cleared when
the backend restarts. The student/faculty switch is a presentation workflow, not
authentication or access control. Use only non-sensitive sample essays, bind the
backend to `127.0.0.1`, and do not expose this demo on a network or use it for
real academic decisions.

The existing authenticated API, database models, records, credentials, OpenAI
provider, rubric management, and review workflows remain available as legacy
functionality. The simplified portfolio UI does not depend on them or modify
their data.

## Run locally on Windows

Prerequisites: Python 3.11+, Node.js 20+, and npm.

Open two PowerShell terminals from the project root.

**Terminal 1 — backend:**

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements-dev.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

The local demo does not need PostgreSQL, database migrations, accounts, or an
OpenAI key. Existing environment settings and database records are not changed.
API documentation is available at http://127.0.0.1:8000/docs.

**Terminal 2 — frontend:**

```powershell
cd frontend
npm install
npm run dev
```

Open http://localhost:5173, select **Student demo**, upload a text-based PDF or
TXT, then use **Faculty demo** to review and approve the evaluation. The student
results page shows criterion feedback after approval.

Scanned/image-only PDFs need the optional OCR dependencies and local OCR
configuration. Typed PDF and TXT workflows do not load the OCR model.

## Tests and checks

Backend, from `backend`:

```powershell
.\.venv\Scripts\Activate.ps1
pytest
```

Frontend, from `frontend`:

```powershell
npm test
npx tsc --noEmit
npm run build
```
